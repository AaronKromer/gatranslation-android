Voice Transcription App

Description

Voice Transcription App is a mobile application developed as a university project. Its main purpose is to convert voice recordings into written text using speech recognition technology.

The app allows users to record audio and automatically generate text from their speech in a simple and intuitive way.

Features

Voice recording directly from the app.

Automatic speech-to-text transcription.

Display of the generated text.
